# AFTERGLOW — Interactive 2D visual study

A responsive, single-page cigarette-themed visual experience built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Open `index.html` in a modern browser.
2. For development, use VS Code's Live Server extension.

## Interactions
- Move the pointer over the stage to influence the illustrated object and smoke drift.
- Use **SMOKE: ON** to pause/resume the smoke animation.
- Use **RESET ATMOSPHERE** to restart the animation.
- Select **ANOTHER LINE** to cycle through the original atmospheric quotes.

## Publish
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository. Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

This is a fictional visual artwork and does not promote tobacco use.
